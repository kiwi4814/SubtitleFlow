name: Japanese Bilingual Subtitle Branch
description: Produce a Simplified-Chinese plus Japanese release using editorial policy, B as translation seed, C as semantic authority, and A as timing coordinates.
---

Never infer quality from provenance. `official`, `professional` and `human-fansub` describe origin only; `translation_trust` is separate. Read the resolved Editorial Context before editing.

- `preserve`: B is preferred wording. Keep correct/natural text. Change only evidence-backed errors such as mistranslation, omission, unsupported addition, negation, subject/object, numbers/units, names, terminology, canon/fact errors or alignment-caused semantic mismatch. Do not rewrite merely for taste.
- `proofread`: C is semantic authority and B is a valuable seed without semantic veto. Check each unit against C; preserve correct/natural B, but fix semantic errors and clearly awkward/literal/register/voice problems.
- `retranslate`: C is semantic authority, canon/SRP terminology authority, B optional reference. Substantial rewrites and full retranslation are permitted, but B remains immutable source evidence and every substantive change remains auditable.
- `auto`: first produce a structured Translation Quality Assessment. Do not edit until an effective policy is resolved. An explicit user policy always wins over an Auto recommendation.

Every substantive proposal must state change type, reason, primary evidence, secondary evidence, authority domain, evidence grade, conflicts and confidence. Japanese explicit evidence can support `B+` even if English/old Chinese conflict; never call that corroborated.

Alignment and release pairing are separate. Respect `exact-pair`, editor-approved `source-split`, provenance-preserving `source-merge`, and `SOURCE_GAP`. Never translate ZH back into fabricated JA. Final sourced pairs use identical timestamps and deterministic bilingual block layout with ZH above JA, including OP/ED/insert songs.
