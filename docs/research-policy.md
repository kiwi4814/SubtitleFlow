# Research policy

Project canon should survive many titles, so evidence quality matters.

Preferred order:

1. official publisher/studio/localized release metadata and subtitles;
2. first-party reference books/databases;
3. reputable encyclopedic/reference sources;
4. community material for gaps, historical fan translations or contested usage.

Record what each source supports. Separate current official naming from historical dub/fansub naming. A historical alias can be useful evidence without being accepted as the release canonical form.
