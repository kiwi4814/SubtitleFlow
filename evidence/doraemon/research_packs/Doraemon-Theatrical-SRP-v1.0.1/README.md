# Doraemon Theatrical Subtitle Research Pack v1.0.1

本包是 Subtitle Research Pack（SRP/1.0），用于 **哆啦A梦主线剧场版 M01–M45（1980–2026）** 的字幕术语归一化。目标不是把所有中文字符串做机械替换，而是让 SubtitleFlow 按“日文实体 → 地区分支 → 作品/配音分支”选择正确译名。

## 1. 本次冻结的边界

- 覆盖已上映主线电影 `M01`–`M45`；2005 年无主线新作。
- `M41` 日文标题含 `2021`，实际上映年为 2022。
- 2027 已公布的新作不进入本 v1，因为尚未形成可用于现有字幕工程的完整地区本地化证据。
- 不把 `STAND BY ME` 等旁系电影并入主线编号。

## 2. 四个输出/保护分支

1. `jp-audio-zh-cn-modern`：日配 → 大陆现代简中（大陆词汇 + 简体字形）。
2. `jp-audio-zh-tw-modern`：日配 → 台湾现代繁中（保留为可选地区本地化分支）。
3. `tw-dub-faithful-zh-hans`：**台湾国语配音 → 台配忠实简中字幕**。音频决定词汇，`zh-Hans` 只决定显示为简体字；禁止因为“是简体”就套用大陆词典。
4. `tw-dub-2026-modern-zh-hans-candidate`：2026 台湾重配候选分支；先实听确认台配口播专名，再输出简体。

### 为什么台配简中不是 `zh-CN`

`zh-CN` 在本项目里代表大陆本地化分支，包含大陆术语选择；而你要的台配字幕只是“字形为简体”，词汇仍属于台湾国语配音。SRP 因此使用 `zh-Hans` 表示简体字形，并通过 `tw-dub-*` branch 保存台湾配音血统。

### 历史旧名的处理

- 大陆：`机器猫 / 小叮当 / 叮当` 被记录为 `哆啦A梦` 的 **deprecated input aliases**。
- 台湾：`小叮噹 / 宜靜 / 技安 / 阿福 / 王聰明 / 小叮鈴` 分别关联现代 `哆啦A夢 / 靜香 / 胖虎 / 小夫 / 出木杉 / 哆啦美`。
- **deprecated ≠ forbidden**。这些旧名在历史材料、旧配音或旧字幕里可能是真实存在的证据。现代日配字幕可以归一化；配音忠实字幕不得擅改口播。

## 4. 这次特别冻结的“同一日文词在不同作品/地区不同译名”

- `パピ`：M06 大陆当前授权目录为 **巴比**；M41 大陆 2022 发行资料为 **帕比**；M41 台湾官方为 **巴比**。因此必须 title-scope，禁止做全系列 `パピ -> 某一个名字`。
- `もしもボックス`：大陆授权页为 **如果电话亭**；台湾 2008 官方电影页为 **假設電話亭**，2016 授权出版物为 **如果電話亭**。本包把台湾 `如果電話亭` 设为 preferred，同时保留 `假設電話亭` 为 accepted official variant。

## 5. 电影标题映射

`terms.jsonl` 已写入：
- 大陆：M01–M34、M36–M44 的当前可证标题；M35 与 M45 保留为 unresolved。
- 台湾：当前官方电影页可证的现代电影标题（M26 起的大部分作品），以及可由授权电影出版物直接证明的 M11–M14；M29 等缺口不猜。

标题规则是 **work identity / UI / 文件命名规则**，不是对白替换规则。

## 6. 证据等级

本包优先级：
1. 日本官方：确认原文实体、电影身份与 source canon。
2. 台湾官方授权站 / 授权出版物：确认 zh-TW 当前/历史授权用词。
3. 大陆正版平台、内地正式发行/译制链及官方电影账号：确认 zh-CN。
4. 权威媒体/机构：补充正式上映译名。
5. 用户 Evidence Library：只用于项目来源、轨道身份、旧字幕候选，不反向冒充官方翻译。

## 7. 为什么 `.tc` 不能直接当台配/台湾官方字幕

你的 Evidence Library 已经明确把“繁体脚本分支”和“台湾来源/台配来源”拆开。繁体字幕可能只是简繁转换；因此 `jp-audio-zh-tw-modern` 必须用台湾授权证据，`tw-dub-faithful-zh-hans` 则必须进一步有音轨实听或可靠台配转录；确认口播词后只做简体字形输出，不做大陆词汇替换。

## 8. SubtitleFlow 应如何消费

建议解析顺序：
1. 从日文字幕/音频识别语义实体，而不是对中文做全局字符串替换。
2. 选择 branch：`jp-audio-zh-cn-modern` / `jp-audio-zh-tw-modern` / `tw-dub-faithful-zh-hans`。
3. 按 scope 优先级取规则：`title+branch > series+branch > title > series`。
4. 现代日配分支只自动输出 `accepted` 且 `locked/preferred` 的 target。
5. `deprecated` 只用于识别旧输入并提示归一化；`accepted_aliases` 是仍可接受的授权变体。
6. 遇到 `unresolved` 或没有 title-level 证据的专名，不猜，进入 Research/Review Gate。
7. 台配忠实简中分支先听音频；例如音轨实际说“技安”，输出写“技安”；说“宜靜”，输出写简体“宜静”；说“小叮噹”，输出写简体“小叮当”。如果音轨实际说“胖虎/静香/哆啦A梦”，则按实际口播写，绝不由旧字幕反推。

- 台湾 M29 当前官方电影索引缺专门条目，本包不从大陆标题或繁转结果推断。

- 每部电影的一次性小角色/小地名/只出现一次的秘密道具并未全部穷举；v1 只冻结已取得可靠区域证据的高影响项。遇到未列项时应继续走 SRP Research Gate，而不是模型自由翻译。

## 10. 文件说明

- `manifest.json`：包身份、语言与分支。
- `entities.jsonl`：人物/道具/地点/组织/45 部电影实体。
- `facts.jsonl`：电影身份、年份、项目来源事实。
- `terms.jsonl`：可供 SubtitleFlow 解析的地区映射。
- `decisions.jsonl`：现代分支、台配忠实、历史旧名、scope 等策略。
- `sources.jsonl`：来源目录。
- `evidence.jsonl`：每条来源支持/冲突的 claim。
- `unresolved.jsonl`：明确不能自动决定的事项。

## 11. 使用警告

**不要把 `terms.jsonl` 当成普通 search/replace 字典直接遍历。** `野比大雄` 与 `大雄`、`剛田武` 与 `胖虎`、M06/M41 的 `パピ` 等都说明必须先识别语义与 scope。

本包的设计原则是：**宁可留下 unresolved，也不为了“看起来完整”伪造大陆/台湾官方译名。**
